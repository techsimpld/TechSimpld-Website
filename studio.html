Own Your Channel Telemetry

Why I Replaced Paid Creator Extensions

Commercial YouTube plugins like VidIQ and TubeBuddy charge recurring monthly fees, inject cluttered overlays into your browser, and lock historical lookups behind higher tiers. TechSimpld Studio flips that model: you host the backend yourself and keep a permanent local record of every metric and comment.

Typical SaaS Creator Plugins

  • Recurring monthly subscriptions: Cancel your plan and your saved research, keyword lists, and historical audits vanish.
  • Browser extension overhead: Heavy scripts injected into YouTube Studio tabs with constant upsell banners.
  • Third-party data collection: Your channel OAuth tokens and analytics pass through external vendor servers.
  • Locked AI models: You pay whatever markup the vendor charges for generic prompt wrappers.

TechSimpld Studio (Self-Hosted)

  • 100% local SQLite archive: Every snapshot, transcript, and viewer comment lives in ./data/studio.db on your server.
  • Focused strictly on your own channel: Uses official YouTube Data API v3 and YouTube Reporting API endpoints with zero third-party telemetry.
  • Bring your own AI engine: Route bulk jobs to free local Ollama models or connect Claude, OpenAI, and Gemini through LiteLLM.
  • MIT licensed and auditable: Clone the repo, inspect every route, run all 105 pytest checks, and customize it for your workflow.
Inside the Application

Built Around Decisions Creators Actually Make

Instead of burying metrics across a dozen YouTube Studio tabs, each view in TechSimpld Studio answers a concrete editorial question: when to publish, where viewers drop off, what hardware your audience runs, and which links in old descriptions have broken.

Module 01 / Channel Intelligence

Channel Analytics, 48h Velocity & Best Time Heatmap

Track your channel's average click-through rate from YouTube Reporting API bulk CSVs alongside subscriber versus non-subscriber discovery ratios and average watch duration.

  • Long-Form vs. Shorts Split: Segregates catalog view share, engagement rates, and average performance by format.
  • 48-Hour Ignition Curve: Monitors hourly launch pacing in UTC against your channel's historical baseline envelope to catch weak packaging early.
  • Empirical-Bayes Publish Heatmap: Blends your past breakout uploads with timezone-aware audience activity to pick reliable release windows.
  • Evergreen Decay & Passive Floor: Flags older videos losing search momentum and tracks your daily baseline view floor.
Module 02 / Audience & Research

Audience Knowledge Graph, CRM & Tech Stack Parser

Comment sections hold your best future video topics, yet YouTube buries them after a week. TechSimpld Studio archives viewer comments locally and parses recurring questions and tools automatically.

  • Superfan Leaderboard: Identifies loyal commenters with three or more lifetime comments while automatically excluding your own creator replies.
  • Tech Ecosystem Fingerprint: Scans comment threads for mentions of Docker tools, hypervisors, OS choices, and networking gear so you know what your viewers actually run.
  • Question & Idea Miner: Extracts unanswered viewer questions to feed directly into your content roadmap.
  • Own-Channel Transcript Vault: Full-text search across your own archived video transcripts with exact jump timestamps (&t=...s).
Module 03 / Packaging & Retention

Retention Curve & End-Screen Timing Optimizer

Most creators drop YouTube End Screens into the final 20 seconds after the majority of viewers have already clicked away. This module plots your real retention trajectory and pinpoints exact timestamps for cards and outros.

  • Outro Cliff Detection: Spots the exact second exit velocity spikes so you can place end-screen cards while viewers are still watching.
  • Intro Hook Benchmark (0:30): Measures what percentage of viewers survive the opening 30 seconds across your catalog.
  • 0 to 100 SEO Pre-Flight Score: Checks title hook clarity, description depth, tags, thumbnail resolution, and Shorts discovery metadata before publish.
  • Click Magnet Matrix & Shorts Companion: Plots CTR against average view duration and includes a Shorts script teleprompter for repurposing long-form guides.
Deployment

Deploy in Minutes on Docker, Proxmox LXC, or Windows

Choose your platform below. Each installer clones the repository, creates a .env file with a freshly generated SESSION_SECRET_KEY, and initializes the local ./data directory. Once running, open http://localhost:8000/settings to add your YOUTUBE_API_KEY and YOUTUBE_CHANNEL_ID.

Fastest: One-Line Docker Installer

Clones the repo, generates secrets in .env, and starts the stack via Docker Compose.

bash 
curl -fsSL https://raw.githubusercontent.com/techsimpld/TechSimpld-Studio/main/scripts/install-docker.sh | bash

Manual Docker Compose Deployment

Prefer to inspect the files before running? Clone manually, edit .env, and bring the container up.

bash 
git clone https://github.com/techsimpld/TechSimpld-Studio.git
cd TechSimpld-Studio
cp .env.example .env
# Add YOUTUBE_API_KEY and YOUTUBE_CHANNEL_ID in .env
docker compose up -d

One-Line Native Installer (Python 3.11+)

Sets up a Python virtual environment, installs dependencies, creates .env, and starts Uvicorn on port 8000.

bash 
curl -fsSL https://raw.githubusercontent.com/techsimpld/TechSimpld-Studio/main/scripts/install-local.sh | bash -s -- --start

Manual Virtual Environment Setup

For always-on Proxmox LXC containers, the repository README also includes a ready-to-use systemd unit file.

bash 
git clone https://github.com/techsimpld/TechSimpld-Studio.git
cd TechSimpld-Studio
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
uvicorn app.main:app --host 0.0.0.0 --port 8000

One-Line PowerShell 5.1 Installer

Requires Python 3.11+ and Git on Windows. Runs natively with no Docker Desktop required.

powershell 
irm https://raw.githubusercontent.com/techsimpld/TechSimpld-Studio/main/scripts/install-local.ps1 | iex

Manual Windows Setup

Clone, activate the virtual environment, copy .env.example, and run Uvicorn locally.

powershell 
git clone https://github.com/techsimpld/TechSimpld-Studio.git
cd TechSimpld-Studio
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
uvicorn app.main:app --host 0.0.0.0 --port 8000
Architecture & Operations

Multi-Model AI Routing & Security Hardening

TechSimpld Studio was engineered for home lab operators who care about API costs, quota limits, and reverse-proxy security. Every safeguard below ships enabled or configurable via environment variables.

Multi-Model AI Orchestrator (LiteLLM)

Assign heavy background summarization to free local models while reserving frontier cloud APIs for high-leverage title and hook ideation. Test and switch models directly from Settings > AI Configuration.

Local LLMs Ollama (llama3.1:8b, mistral, deepseek), vLLM, or LM Studio via OpenAI-compatible endpoints.
Cloud Providers Anthropic Claude, OpenAI ChatGPT (gpt-4o, gpt-4o-mini), and Google Gemini (gemini-2.0-flash, gemini-1.5-pro).
Quota Protection Live tracker for the 10,000-unit daily YouTube Data API v3 budget with automatic Safe Mode throttling at 85%.
Alerting & Guard Gotify push notifications for OAuth token expiry, unauthorized logins, quota spikes, and broken description or affiliate links.

Security & Authentication

Designed to sit cleanly behind Cloudflare Tunnels, Nginx Proxy Manager, or Traefik without exposing secrets to the browser.

Authentication Built-in username/password login (LOCAL_AUTH_ENABLED) or Authentik OIDC Single Sign-On with PKCE.
Container Hardening Runs as non-root user (UID 1000), keeps API keys out of rendered HTML/JS, and auto-generates 32+ char session secrets.
Network Controls Blocks SSRF requests to private IP ranges and cloud metadata endpoints (including AWS IPv6 IMDS), plus same-origin validation on mutations.
Response Headers Enforces X-Frame-Options: DENY, X-Content-Type-Options: nosniff, and Referrer-Policy: strict-origin-when-cross-origin.
Common Questions

Before You Deploy

Does TechSimpld Studio work with the free YouTube Data API v3 tier? +

Yes. Google grants 10,000 free API units per day by default. TechSimpld Studio monitors your daily quota consumption and automatically switches on Safe Mode throttling once usage passes 85%, preventing runaway sync jobs from exhausting your quota.

Do I need paid AI API keys, or can I run everything locally with Ollama? +

Paid API keys are completely optional. You can point LOCAL_AI_BASE_URL at an Ollama, vLLM, or LM Studio instance on your LAN and run transcript summaries and comment mining with zero per-token fees. You can also combine local models with Claude, OpenAI, or Gemini on a per-task basis.

Can I run it on Proxmox without Docker, or on a Windows desktop? +

Yes. In addition to docker compose up -d, the GitHub repository includes native installers for Linux/Proxmox LXC (with a systemd unit example) and Windows PowerShell 5.1 (using a standard Python 3.11+ virtual environment and optional Task Scheduler background startup).

Does TechSimpld Studio send my channel analytics to TechSimpld or any third party? +

No. All channel metrics, video snapshots, transcripts, and viewer CRM entries are written to your local SQLite database at ./data/studio.db. The application communicates only with official YouTube API endpoints and the AI or Gotify servers you configure.

How does Authentik SSO or local login work behind a reverse proxy? +

Set LOCAL_AUTH_ENABLED=True with a strong password for built-in login, or set AUTHENTIK_ENABLED=True with your Authentik OIDC issuer URL for single sign-on. When serving over HTTPS behind a reverse proxy, set SESSION_COOKIE_SECURE=True and list your proxy IP in TRUSTED_PROXY_HOSTS.
